I'm a developer who enjoys turning business problems into practical software solutions.

My work revolves around building web applications, business management systems, e-commerce platforms, mobile app integrations, and AI-powered workflows. I enjoy understanding how a business operates, identifying what can be improved, and building technology that makes those processes simpler.

I'm comfortable working across different layers of a project—from database design and backend logic to frontend interfaces, API integrations, deployment, and ongoing support. I use AI coding agents to accelerate implementation, explore unfamiliar codebases, troubleshoot issues, and improve development workflows. ### How I Approach Development

- **Business first:** Understand the actual problem before choosing the technology.
- **Practical engineering:** Prefer solutions that are maintainable, understandable, and useful.
- **AI with accountability:** AI can accelerate implementation, but code still needs human review, testing, and verification.
- **Integration matters:** Applications should work together, not become isolated pieces of software.
- **Production mindset:** Deployment, security, debugging, documentation, and maintenance are part of development—not afterthoughts.
